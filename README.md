### 操作指南

#### 访谈记录

1. 访谈前创建 Issue，说明访谈目的和问题大纲
2. 访谈后在 `专家访谈/` 创建记录文件
3. 命名格式：`YYYY-MM-DD_[受访者称呼]访谈.md`
4. 使用 `templates/访谈记录模板.md`
5. 关闭对应 Issue 并引用记录文件

#### 活动记录

| 活动类型 | 存放位置 | 必要内容 |
|----------|----------|----------|
| 科普讲座 | `Education/科普活动/` | 活动方案、现场照片、反馈收集 |
| 工作坊 | `Education/工作坊/` | 教案、材料清单、参与者反馈 |
| 公众活动 | `Communication/公众活动/` | 活动策划、执行记录、媒体报道 |
| 队伍合作 | `Collaborations/队伍合作/` | 合作协议、交流记录、成果 |

#### HP 时间线维护

### 注意事项

- **隐私保护**：访谈记录中涉及个人信息需获得授权
- **素材授权**：活动照片中出现的人员需签署肖像使用授权
- **及时记录**：活动后48小时内完成记录
